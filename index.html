Verified 23 October 2026. BridgeAI Operational Systems is open to a UK AI SME with a working TRL 5–6 product and an eligible UK deployer, not a solo founder. A consortium can request £100,000–£200,000, with partial cost funding; the £5 million headline is the competition pot. Check the partner, cost and 8 December gates.

Verified 22 October 2026. NLnet policy v2.0 now bars AI-assisted proposal writing for the 3 November CodeSupply and Restack calls, except disclosed accessibility use; funded work allows read-only AI checks, not AI-generated deliverables. The form still has an AI disclosure field. Read the current rule and resubmission note.

Checked 21 October 2026. AWS Activate’s standard route says Paid account plan; its optional agent page says paid Support plan. Those are different: Basic Support is included and Business Support+ starts at USD 29/month. AWS has not resolved whether premium Support is required for the agent route. Check before buying Support.

Verified 20 October 2026. NLnet CodeSupply closes 3 November at 12:00 CET. The live form asks for a costed technical case and AI-use disclosure; selected work is paid after milestones. Check the form fields before applying.

Verified 19 October 2026. OpenAI accepts rolling applications from active open-source maintainers. Selected applicants may get API credits for maintenance workflows, not a general commercial app budget; the amount and expiry are unpublished. Check the application and use limits.

Checked 18 October 2026. OpenAI describes a partner-VC referral route to possible API credits, not a published amount for every startup. The FAQ lists a VC code and says standard billing starts when credits run out. Check the application and billing gates.

Checked 17 October 2026. AWS can help an AI agent prepare an Activate application, but you review and submit it. The agent page says “paid support plan”; the main programme says “Paid Tier Plan.” AWS treats account and Support plans separately. Do not buy Support based on that wording alone. Check the two routes and sources.

Verified 16 October 2026. Google Start needs a Cloud Billing ID. For qualified India UPI users, a requested INR 500–1,000 can be a real Postpay prepayment, not a temporary card hold. Check the account status and payment type before paying; approval is not guaranteed. Read the billing check.

Check the account before you count a startup credit

Verified 15 October 2026. Microsoft’s updated application guide now excludes Series C and separates a USD 200 no-code start from a USD 1,000 investor-code start. An older live guide still says USD 1,000 without a code. Check the account gate and conflicting amounts.

Checked 14 October 2026. NLnet CodeSupply accepts individual open-source software supply-chain proposals, but does not pay up front. Check the 3 November deadline, European rule and payment timing.

Checked 13 October 2026. AWS Portfolio needs a provider-issued Org ID and affiliation verification; its USD 200,000 ceiling is not a direct award. Check the application route.

Checked 12 October 2026. Interledger has an open USD 50,000 NextGen call, but only an eligible higher education institution can apply. Its founder accelerator is closed and Local Impact is paused. Check the applicant gate before preparing a proposal.

Published earlier on 12 October from 9–10 October research. That release did not include a new issuer check. See the saved credit checks and their original reports.

Updated 2026-10-10. AWS Activate terms allow eligible credit for third-party Bedrock model charges, but the awarded credit’s Applicable products and Application history decide what actually offsets a bill. Check AWS credit coverage before scaling use.

Updated 2026-10-09. Google’s ordinary startup Cloud credits do not pay for third-party Model Garden models. Qualifying Scale members may have a separate partner-model credit; Start members should not count it.

Check the model bill, not just the cloud balance

The Google coverage check separates ordinary credits from a possible USD 10,000 Scale partner-model benefit. Confirm the exact credit and covered charges in your billing account before usage.
